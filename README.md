# STM32 Real-Time Motor Control

## Objective

Development of a real-time motor-control firmware on STM32 using Embedded C.

## Planned Features

- Low-level GPIO configuration
- Timers and interrupts
- PWM motor control
- ADC measurement
- UART communication
- DMA
- Fault detection
- Real-time control
- Unit testing
- Git and CMake

## Target MCU

STM32F407
